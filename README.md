# Cashmere Futures

**Cashmere Futures Lab (CFL)**

The repository for [cashmerefutures.com](https://cashmerefutures.com), an emerging research and collaboration platform focused on cashmere supply chains, communities, sustainability, research, and transformation.

## Main pages

- Home
- About
- Supply Chain
- Communities
- Research
- Cashmere-SDG Hub
- Library
- Global Map
- Collaborate
- Privacy

## Repository structure

- `*.html` — website pages
- `css/` — stylesheets
- `js/` — browser-side JavaScript
- `functions/api/` — contact-form API endpoint
- `CNAME`, `robots.txt`, `sitemap.xml` — deployment and search-engine configuration

The repository is kept intentionally lean; obsolete page experiments, duplicate root-level styles/scripts, and temporary inspection files are not retained.
